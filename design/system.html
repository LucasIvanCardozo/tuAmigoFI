2. Tipografía

El proyecto no declara ninguna fuente: tailwind.config.ts no tiene fontFamily ni src/app/globals.css define font-family. La pila en uso es la de Tailwind v4 por defecto (--font-sans). Los tamaños son los valores por defecto de Tailwind v4.

-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', 'Noto Sans', Arial, sans-serif, 'Apple Color Emoji', 'Segoe UI Emoji', 'Segoe UI Symbol', 'Noto Color Emoji'

Origen: node_modules/tailwindcss/theme.css (Tailwind v4 default --font-sans) · tailwind.config.ts no declara fuentes.
